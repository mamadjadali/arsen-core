# دعوت به عمل و فوتر

## CTA نهایی (solaceCta)

**Heading:**

```
پوست شما شایستهٔ بهترین مراقبت است
```

جایگزین:

```
نوبت خود را رزرو کنید
```

شاعرانهٔ کوتاه:

```
آغاز درخشش، یک تصمیم آرام است
```

**دکمه‌ها:** به‌جای اپ‌استور — لینک‌های واقعی کلینیک:

- رزرو نوبت / تماس  
- اینستاگرام یا واتساپ (در صورت وجود)

> نکتهٔ فنی: فعلاً بلوک `solaceCta` بج‌های فروشگاه اپ دارد؛ برای کلینیک بهتر است بعداً به دو دکمهٔ «رزرو» و «تماس» تغییر کند. تا آن زمان می‌توان heading را عوض کرد و URLها را به فرم/تماس داد.

## فوتر

### خبرنامه

**عنوان:** خبرنامهٔ پوست‌آگاهی  
**Placeholder:** ایمیل شما  
**پیام ضمنی:** نکات فصلی مراقبت پوست — بدون اسپم.

### ستون Brand

- دربارهٔ دکتر  
- خدمات  
- گالری نتایج (در صورت تمایل)  
- مقالات  
- تماس  

### ستون Support

- سوالات متداول  
- آمادگی قبل از درمان  
- مراقبت بعد از درمان  
- حریم خصوصی  
- قوانین نوبت  

### کپی‌رایت

```
© ۱۴۰۵ کلینیک پوست دکتر مریم رنجبر — همهٔ حقوق محفوظ است
```

(سال را با تاریخ واقعی به‌روز کنید.)

### شبکه‌های اجتماعی

فقط پلتفرم‌هایی که فعال‌اند؛ کیفیت > کمیت.

---

## هدر (Navbar)

**برند:** دکتر مریم رنجبر  

**منو پیشنهادی:**

- خدمات  
- درباره  
- مقالات (یا وبلاگ)  
- تماس  

**Secondary CTA:** مشاوره  
**Primary CTA:** رزرو نوبت
